Why this map
Orientation before execution. The skill files (/apple-automation, /apple-app-builder) are the playbook for each node — they contain the phase-by-phase checklists, the macOS-specific gotchas, and the build discipline. This map answers "which skill do I pick up, and when?" — something the skill files can't answer from inside themselves. Start here at the top of any new project session to locate yourself, then invoke the matching skill to get the details.
